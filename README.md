# Vườn Văn

App giúp học sinh lớp 4 luyện viết văn theo SGK Tiếng Việt 4 – Kết nối tri thức với cuộc sống: bản thảo gợi ý, sơ đồ tư duy, kiểm tra chính tả, chấm điểm tự động, trang giáo viên và báo cáo tiến độ.

Chạy hoàn toàn trên máy, không cần mạng, không cần tài khoản.

- Dùng online: https://dungptt-dng.github.io/vuon-van/
- Dùng ngoại tuyến: tải mã về, nháy đúp `MO-APP.bat` hoặc `app/index.html`.

Xem hướng dẫn chi tiết trong [HUONG-DAN.md](HUONG-DAN.md).
